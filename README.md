# Cadenza — feedback

This is where bugs and feature requests for **Cadenza** go. Cadenza makes music locally on your Mac,
iPhone or iPad with ACE-Step 1.5. There is no code here. This repository exists so that anyone can
open an issue.

## Reporting a problem

On a Mac, the quickest way is **Settings → About → Report a problem**. It opens a new issue here
with the app version, build, macOS version and architecture filled in. Nothing else is filled in,
and nothing is sent until you submit the issue yourself. On an iPhone or iPad, open an issue here
directly and include your device and iOS version.

When you describe the problem, include what you did, what you expected, and what happened. On a
Mac with crash reporting turned on, **Settings → Privacy** shows any crash report and lets you read
it before attaching it here.

## Requesting a feature

Open an issue labelled `feature-request`, or 👍 an existing one. Reactions are how requests get
weighed.

## Privacy

Cadenza collects no analytics or usage data. Generation runs on your device. Cadenza connects only
to Hugging Face: to download model weights and, on a Mac, to check whether a model has an update.
You can turn update checks off in Settings. Crash reporting is off by default. When it's on, reports stay on your
Mac, and they only reach anyone if you attach one to an issue.

**Anything you post here is public.** Please don't include lyrics, prompts or audio you'd rather
keep private.
